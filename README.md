 🎲 Guess the Number Game

A simple **Guess the Number** game built with **HTML, CSS, and JavaScript**.  
The player has to guess a random number between **1 and 100** within **10 attempts**.  
After each guess, the game will tell you if the number is **too high** or **too low** until you win or run out of attempts.

 🚀 Features
- Random number generated between 1 and 100.
- Player gets **10 attempts** to guess correctly.
- Hints:  
  - ✅ "Too low" if the guess is smaller.  
  - ✅ "Too high" if the guess is larger.  
- Shows remaining attempts.
- Game ends with a win or loss message.
- **Restart/Play Again** button included.

 🛠️ Tech Stack
- **HTML5**
- **CSS3**
- **JavaScript
